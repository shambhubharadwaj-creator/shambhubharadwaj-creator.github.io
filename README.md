# Shambhu Bharadwaj — Academic Website

This repository contains the source for the academic profile website.

## Publish with GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/(root)`, then click **Save**.
4. Wait a few minutes and visit https://shambhubharadwaj-creator.github.io/.

## Website contents

- `index.html` — responsive academic profile homepage.

Please review and update academic appointments, publication metrics, and profile links before sharing widely.
